# 本地修图工具箱 · Photoshop UXP 面板插件

> 一个完全在 **Photoshop 内部、本机运行** 的修图插件。
> 读取 PS 原生选区 → 调用 PS 自带算法 → 结果直接写回原图层，**分辨率与像素尺寸完全不变，不做任何压缩**。
> 安装方式与「ONIRIC」「耀AI」这类插件完全一致：**把文件夹丢进 PS 的 Plug-ins 目录即可**，
> 不需要 UXP Developer Tool，不需要登录 Adobe 账号，不需要联网。

| 项目 | 说明 |
| --- | --- |
| 插件 ID | `com.local.ps.retouchkit` |
| 类型 | Photoshop UXP 面板（manifest v5，与 ONIRIC v2.3.0 同格式） |
| 技术栈 | 原生 HTML / CSS / JS + UXP batchPlay |
| 支持宿主 | Adobe Photoshop 24.4 及以上（已在 26.5 / 2025 版格式上对齐） |
| 联网需求 | **零网络请求**，不依赖任何云端 API、不上传图片 |
| 处理位置 | 100% 本地，由 Photoshop 自身算法完成 |

## 1. 功能总览

### 功能 1：清除杂物 / 路人
- 读取你在 PS 里用**原生选区工具**（矩形选框、套索、快速选择、魔棒……）画出的选区；
- 调用 PS 内置的 **内容识别填充**（编辑 → 内容识别填充，菜单 ID `contentAwareFill`）：
  由 PS 自己从选区周边取样、重建像素；
- 新像素**直接写回当前图层**，不新建可见图层、不改变图层顺序与名称；
- 处理完自动取消选区，方便立刻看效果。

### 功能 2：衣物褶皱抚平
- 读取同一个原生选区，把选区**当作蒙版**使用；
- 在选区内执行 **表面模糊**（也可换成特殊模糊 / 蒙尘与划痕）：只抹平褶皱这类低频明暗起伏，
  对布料纹理这种高频细节影响很小；
- 再用「编辑 → 渐隐」按**修复强度**把模糊结果与原图混合，防止糊成塑料感；
- 结果**直接落在原图层上**，不新建图层、不改变图层结构，`Ctrl+Z` 一步即可撤销。

### 全程硬性保障
- ✅ 只调用 PS 本地能力，插件代码里**没有任何网络请求**（无 `fetch`、无 `XMLHttpRequest`）；
- ✅ 面板是 **PS 内部停靠面板**，不打开外部浏览器窗口；
- ✅ 只读取 PS 原生选区，插件自己**不画选区**；
- ✅ 处理前后自动校验文档 `宽 × 高 @ DPI` 指纹，**一旦不一致立即中止并提示**；
- ✅ 没有文档 / 没有选区时，面板内浮层 + 运行日志双提示，不静默失败；
- ✅ 词条内联在 JS 里，即使读不到任何外部文件，面板也不会出现空白文案。

## 2. 工程结构

**插件本体**就是下面这个文件夹，把它整体复制到 PS 的 `Plug-ins` 目录即可（不需要 npm、不需要构建）：

```
com.local.ps.retouchkit/          ← 插件根目录（复制这一个文件夹）
├── manifest.json                 ← UXP 插件清单（manifest v5，PS 24.4+）
├── index.html                    ← 面板 UI（两个功能按钮 + 参数 + 日志）
├── css/
│   └── style.css                 ← 面板样式（自动适配 PS 深色 / 浅色界面）
├── js/
│   ├── i18n.js                   ← 国际化（中/英词条已内联，不依赖外部文件）
│   └── main.js                   ← 核心逻辑：读文档 / 读选区 / 本地修复 / 分辨率校验
├── i18n/
│   ├── zh_CN.json                ← 词条备份（可选，仅作覆盖来源）
│   └── en_US.json                ← 词条备份（可选）
├── icons/
│   ├── plugin.png                ← 插件列表图标（48×48）
│   ├── plugin@1x.png             ← 面板标签图标（23×23，manifest 里 scale:[1,2] 会去找它）
│   ├── plugin@2x.png             ← 高分屏图标（46×46）
│   └── make_icon.py              ← 图标生成脚本（可选）
└── README.md                     ← 本文档
```

> ⚠️ 图标命名规则：manifest 里写了 `"scale": [1, 2]`，UXP 就会按
> `plugin@1x.png` / `plugin@2x.png` 这两个**固定后缀**去找图标。
> 文件缺失不会导致插件加载失败，但日志里会刷 `Scaled Icon ... not found`，
> 面板图标也会显示得偏模糊。本插件已按规则提供这三个文件。

> ⚠️ 关键：`manifest.json` 必须**直接位于插件文件夹根目录**，且与 `index.html` 同级。
> 不要出现 `com.local.ps.retouchkit\com.local.ps.retouchkit\manifest.json` 这种多套一层的情况。

## 3. 安装：把文件夹丢进 Plug-ins 目录

这是**唯一需要做的操作**，全程离线、不需要任何 Adobe 官方工具或账号。

### 步骤

1. **完全退出 Photoshop**（不是关文档，是退出程序；任务管理器里确认没有 `Photoshop.exe`）。
2. 用**管理员身份**打开文件资源管理器（因为 PS 装在 `D:\` 且多为受保护目录）：
   开始菜单搜「资源管理器」→ 右键 → **以管理员身份运行**。
3. 找到你的 PS 安装目录下的 `Plug-ins` 文件夹：

   ```
   D:\photo shop\Adobe Photoshop 2025\Plug-ins
   ```

   > 这个目录里现在应该能看到 `ONIRIC_v2.3.0`、`YAO_V1.0.4` 等文件夹——说明它就是要用的位置。
4. 把整个 **`com.local.ps.retouchkit`** 文件夹复制进去，最终结构为：

   ```
   D:\photo shop\Adobe Photoshop 2025\Plug-ins\com.local.ps.retouchkit\manifest.json
   D:\photo shop\Adobe Photoshop 2025\Plug-ins\com.local.ps.retouchkit\index.html
   D:\photo shop\Adobe Photoshop 2025\Plug-ins\com.local.ps.retouchkit\js\main.js
   ...
   ```

5. **启动 Photoshop**，新建或打开一个文档，然后打开面板：

   - 菜单 **增效工具（Plug-ins）→ 本地修图工具箱**；
   - 若那里没有，去 **窗口 → 扩展功能 / 增效工具面板** 里找；
   - 面板可以被拖到右侧面板组停靠，也可以拖出来当浮动小窗口
     （尺寸限制 260×320 ~ 1600×1600，可自由缩放）。

6. 首次加载如果面板是空的，关掉 PS 再开一次（UXP 插件目录只在启动时扫描一次）。

### 为什么这样就能用

你的 PS 2025（26.5）在启动时会扫描应用目录下的 `Plug-ins` 文件夹，
发现其中任何一层子目录里的 `manifest.json` 是 UXP 清单，就把对应面板注册到「增效工具」菜单。
`ONIRIC_v2.3.0` 用的正是 `manifestVersion: 5` + `entrypoints: [{ type: "panel" }]` 这一套格式，
本插件的清单格式与它保持一致，因此走的是同一条加载路径。

## 4. 安装位置怎么选（主用 / 备用）

如果 `D:\...\Adobe Photoshop 2025\Plug-ins` 放进去后菜单里没出现，按顺序试下面两个位置
（都是「丢文件夹」的方式，都不需要官方工具）：

| 优先级 | 位置 | 说明 |
| --- | --- | --- |
| ①（主用） | `<PS安装目录>\Plug-ins\com.local.ps.retouchkit\` | 最直观，与 ONIRIC / 耀AI 同目录，扫描最可靠 |
| ②（备用） | `%APPDATA%\Adobe\UXP\Plugins\External\com.local.ps.retouchkit\` | 用户级 UXP 插件目录，`External` 专门放第三方插件；目录不存在就手动新建 |
| ③（备用） | `%APPDATA%\Adobe\UXP\Plugins\com.local.ps.retouchkit\` | 同上，去掉 `External` 一层 |

`%APPDATA%` 一般是 `C:\Users\你的用户名\AppData\Roaming`，可以直接在资源管理器地址栏输入
`%APPDATA%\Adobe\UXP\Plugins` 回车跳转。

> 两个位置可以只放一个，也可以都放。都放时以主用位置为准。
> 每次改完位置都要**彻底重启 Photoshop**。

### 如果三个位置都试了还是不出现

**第一件事：去看 Photoshop 的 UXP 加载日志**，它会直接告诉你插件为什么被丢弃（比猜快 100 倍）：

```
%APPDATA%\Adobe\Adobe Photoshop 2025\Logs\UXPLogs_*.log
```

挑**最新时间戳**的那个文件（每次启动 PS 生成一个），搜索插件的 id，例如：

```powershell
$log = Get-ChildItem "$env:APPDATA\Adobe\Adobe Photoshop 2025\Logs\UXPLogs_*.log" |
       Sort-Object LastWriteTime -Descending | Select-Object -First 1
Select-String -Path $log.FullName -Pattern 'retouchkit|manifest|Invalid|Error' -Encoding UTF8 |
       ForEach-Object { $_.Line }
```

日志里能看到三类结果：

| 日志内容 | 含义 |
| --- | --- |
| `Plugin com.local.ps.retouchkit : ...` + `Info` | 清单被接受，插件已注册 |
| `Failed to parse the manifest.json file.` | 清单有语法/字段错误，插件被整个丢弃（下面第 1 条是最常见原因） |
| 整份日志里搜不到插件 id | PS 根本没扫到这个文件夹，属于位置问题（见下面前 4 条） |

**最常见的清单错误：`label` 里用了下划线 locale。**
UXP 的 locale 命名必须是**连字符**（`zh-CN` / `en-US`），写成 `zh_CN` / `en_US` 会导致：

```
Locale string en_US is in invalid format for the plugin com.local.ps.retouchkit
Plugin com.local.ps.retouchkit : Invalid format for label in Plugin Manifest
Failed to parse the manifest.json file.
```

本插件的清单已经修正，`label` 只保留 `default`（与同环境可正常加载的 ONIRIC 保持一致）。
如果你自己改清单，请务必遵守这条。

其他排查点：

1. **清单格式**：确认文件名是 `manifest.json`（不是 `.txt`），JSON 能被正常解析。
2. **目录层级**：`manifest.json` 和 `index.html` 必须在同一层，中间不能多套文件夹。
3. **权限**：`D:\` 下写入需要管理员权限；复制时若提示需要权限，说明没复制成功。
4. **版本**：`帮助 → 关于 Photoshop` 确认版本 ≥ 24.4。
5. **残留进程**：任务管理器里结束所有 `Photoshop.exe` 后再启动（插件目录只在启动时扫描一次）。

## 5. 在 PS 里怎么用（操作演示）

### 演示一：清除背景里的路人 / 杂物

| 步骤 | 操作 |
| --- | --- |
| 1 | 在 PS 中打开照片，`Ctrl+J` 复制一份图层（**强烈建议**，随时可对比原图）。 |
| 2 | 选中要修复的图层（图层面板里点蓝它）。 |
| 3 | 用 PS **自带**选区工具框住路人：矩形选框 `M`、套索 `L`、快速选择 `W` 都行。<br>选区可比路人**多框 2~5 px**，给算法留出取样余量。 |
| 4 | 打开插件面板：`增效工具 → 本地修图工具箱`。<br>面板顶部状态条应显示文档名、`宽 × 高 px`、`ppi`，**“选区”一栏变绿**并显示选区尺寸。 |
| 5 | 点 **【清除杂物 / 路人】**。 |
| 6 | 稍等 1~3 秒（大图稍慢），选区被自动取消，路人消失，像素已写回**当前图层**。 |
| 7 | 有残留时：`Ctrl+Z` 撤销 → 缩小选区只框残留部分 → 再点一次；<br>或点 **【用修复画笔再补一刀】**（自动切到修复画笔，手动描几笔）。 |

> 处理完成后，面板日志会打印 `分辨率保持不变：4032×3024`，确认图片没有被缩放或压缩。

### 演示二：抚平衣物褶皱（保留布料纹理）

| 步骤 | 操作 |
| --- | --- |
| 1 | 选中衣物所在的像素图层（若是智能对象，先 `右键 → 栅格化图层`）。 |
| 2 | 用套索 / 快速选择圈出**有褶皱的那一片衣服**（不用整件衣服，分区域处理效果更好）。 |
| 3 | 在面板“衣物褶皱抚平”区调参：<br>· **模糊半径**：褶皱有多宽就填多少像素（全身照常见 6~15）；<br>· **边缘阈值**：默认 16，想更保纹理就调小到 8~12；<br>· **修复强度**：默认 70%，追求更平就调到 85%，想自然就降到 55%。 |
| 4 | 点 **【抚平衣物褶皱】**。 |
| 5 | 观察结果：褶皱的明暗起伏被压平，布料编纹 / 针织纹理仍在；<br>选区边缘有柔和的过渡，不会出现“一块补丁”。 |
| 6 | 不满意：`Ctrl+Z` 撤销，**先提高“边缘阈值”（如 16 → 26）再降低“修复强度”（70% → 55%）**，<br>通常就能在“更平”与“更自然”之间找到平衡；确实还不够平，再回头加大模糊半径。 |

## 6. 参数怎么调

| 参数 | 范围 | 默认 | 作用与建议 |
| --- | --- | --- | --- |
| 模糊半径 | 1–50 px | 8 | 褶皱的**宽度**大致是多少像素就填多少。像素级小图 3~6，4000 万像素大图 10~20。 |
| 边缘阈值 | 2–60 | 16 | 表面模糊的“保边”阈值。**越小越保纹理也越不糊**；想要强力去皱可降到 6~10。 |
| 修复强度 | 10–100 % | 70 | 模糊结果与原图的混合比例。**100% = 完全使用模糊结果**（最平但最假），60~80% 是自然区间。 |
| 模糊算法 | 3 选 1 | 表面模糊 | 表面模糊最均衡；特殊模糊适合有明显分界的服装；蒙尘与划痕/中值对细小纹理保护最好但慢。 |
| 选区羽化 | 0–30 px | 0 | 大于 0 时在选区边缘做渐变过渡，适合处理明显的“补丁边界”。一般保持 0。 |
| 记住参数 | 开 / 关 | 开 | 开启后参数优先写入面板本地存储；若宿主允许，再额外写一份到用户数据目录。写入失败会自动跳过，不影响使用。 |

## 7. 实现原理

### 7.1 怎么读“PS 原生选区”
UXP 没有直接的 `document.selection` DOM 接口，插件用 `batchPlay` 读取选区通道：

```js
{
  _obj: "get",
  _target: [{ _property: "selection" }, { _ref: "document", _enum: "ordinal", _value: "targetEnum" }]
}
```

返回结果里的 `selection.path` 数组就是选区轮廓：

- 矩形 / 椭圆选框 → 一个含 4 个锚点的子路径；
- 套索、快速选择、魔棒 → 一条含若干锚点的子路径。

数组为空即代表**没有选区**（这是 PS 里最可靠的判据）；遍历所有锚点取并集就能得到选区包围盒，
用于面板显示与“选区过小”判断。

### 7.2 功能 1 怎么“清除”并写回原图层

1. 先按“选区羽化”参数对选区做 `feather`，软化接缝；
2. 触发 PS 本地菜单命令：

   ```js
   { _obj: "menuItemClass", menuItem: "contentAwareFill",
     _target: [{ _ref: "application", _enum: "ordinal", _value: "targetEnum" }] }
   ```

   该命令由 **Photoshop 自身**执行内容识别算法，产生的像素**直接落在当前图层的选区范围内**，
   因此天然满足“覆盖到原有图层”“不新建图层”“不改变画布尺寸”；
3. `deselect` 取消选区；
4. 重新读取文档宽高与 DPI，与处理前比对，不一致就抛错并提示撤销。

### 7.3 功能 2 怎么“抚平但不糊”

整层模糊会不可逆地丢掉纹理，所以采用 **“选区内滤镜 + 渐隐混合”**，全程不新建图层：

```
① feather 软化选区边缘（可选，默认 0）
② 对“当前原图层”执行表面模糊，并在描述符里挂上选区限制：
      selection: { _ref: "channel", _enum: "channel", _value: "selection" }
   → 滤镜只在选区内部生效，选区外的像素一点不动，天然形成一张“只修选区”的蒙版
③ 立刻调用“编辑 → 渐隐（Fade）”按“修复强度”回落混合比例：
      { _obj: "fade", to: { _obj: "opacity", _unit: "percentUnit", _value: strength } }
   → strength = 70% 即保留 70% 的模糊结果 + 30% 的原始像素，
     既压平褶皱的低频明暗起伏，又把布料编纹/针织纹理留在画面里
④ deselect 取消选区 + 校验分辨率
```

**表面模糊为什么能保纹理**：它只对“与邻域像素差值小于阈值”的区域做平均。
布料的编纹属于高频细节，差值超过阈值就被自动保护，因此不会被抹掉；
而褶皱是大面积的低频明暗过渡，会被平滑掉。这正是“抚平但不糊”的关键。

### 7.4 为什么“不会压缩图片”

- 插件从不调用 `imageSize`（图像大小）、`resizeImage`、`export`、`saveAs`
  等任何会改变像素尺寸或触发重采样的命令；
- 只使用 `surfaceBlur` / `smartBlur` / `dustAndScratches` / `contentAwareFill` 这类**逐像素本地运算**；
- 每个功能结束时都会比对处理前后的 `宽 × 高 @ DPI` 指纹（`verifyResolution`），
  一旦发现变化就中止并提示，绝不会悄悄保存一张被缩小的图。

## 8. 常见问题 FAQ

**Q1：复制到 `Plug-ins` 时提示“需要管理员权限 / 目标文件夹访问被拒绝”。**
A：以管理员身份运行文件资源管理器再复制。也可以先把文件夹复制到桌面，
再用管理员身份的资源管理器移动到 `Plug-ins` 下。

**Q2：放进去了，但「增效工具」菜单里没有。**
A：① 必须先**完全退出 PS** 再复制，复制完再启动；
② 确认层级是 `Plug-ins\com.local.ps.retouchkit\manifest.json`（不要多套一层）；
③ 换个位置试：`%APPDATA%\Adobe\UXP\Plugins\External\com.local.ps.retouchkit\`（见第 4 节）。

**Q3：点按钮提示“没有检测到选区”，但我明明画了。**
A：① 选区可能因为切换工具 / 新建图层已经消失，重新框选后点 **【刷新状态】** 确认；
② 选区的“蚂蚁线”处于**隐藏**状态（`Ctrl+H`）时依然算有选区，插件能读到，不受影响；
③ 若选区小于 2×2 像素会被判定为无效，请重新框选。

**Q4：提示“当前图层不支持像素级修复（智能对象 / 文字 / 形状 / 调整层 / 图层组被锁定）”。**
A：`右键图层 → 栅格化图层`；若是背景层被锁定，插件已自动放行，无需处理。
文本层、形状层、智能对象都不能直接做像素级修复。

**Q5：提示无法调用“内容识别填充”。**
A：可能原因：① PS 版本过旧；② 文档是 CMYK / 灰度 / 32 位模式
（内容识别填充要求 8 位或 16 位 RGB）；③ 有对话框挡住了 PS，先按 `Esc`。
此时可以改用 **【用修复画笔再补一刀】** 手动修。

**Q6：褶皱抚平后还是有点糊 / 不够平。**
A：糊 → 提高**边缘阈值**（如 16 → 28）或降低**修复强度**（70% → 50%）；
不够平 → 提高**修复强度**（→ 85%）或增大**模糊半径**。
另外建议**分区域分次处理**，一次只框一片褶皱，效果远好于整件衣服一次搞定。

**Q7：处理大图很慢或者 PS 卡住。**
A：所有运算都是 PS 自身在**原分辨率**下做的，4000 万像素以上图片，
表面模糊需要几秒到十几秒属正常。建议：
① 每次只框需要修的小范围；② 避免在“有大量图层”的文档里连续操作；③ 处理期间不要点击画布。

**Q8：日志里出现 `Photoshop is busy`。**
A：说明有 PS 对话框（滤镜面板、保存对话框等）挡着，`Esc` 关掉再点一次按钮即可。

## 9. 卸载与彻底清理

1. 退出 Photoshop；
2. 删除你放进去的插件文件夹：
   - `D:\photo shop\Adobe Photoshop 2025\Plug-ins\com.local.ps.retouchkit`
   - 以及（如果放过）`%APPDATA%\Adobe\UXP\Plugins\External\com.local.ps.retouchkit`
3. 重新启动 Photoshop，菜单项即消失；
4. （可选）清理参数残留：删除 `%APPDATA%\Adobe\UXP\PluginStorage\com.local.ps.retouchkit\`
   下的 `retouch-kit-settings.json`。

## 11. 附：开发期自检脚本

工作区根目录 `C:\ps自制插件\tools\` 下有开发期用的离线自检脚本，
它**不属于插件本体，不要复制进 Plug-ins**：

| 文件 | 作用 |
| --- | --- |
| `selftest.js` | 在 Node 里 mock 出 PS/UXP 环境，把 `js/main.js` 实跑一遍 |
| `build_dicts.py` | 把 `i18n/*.json` 转成可内联的 JS 词条字面量 |
| `build_i18n.py` | 用上面的字面量重新生成 `js/i18n.js` |

运行自检（需要 Node.js 18+，纯离线，不会真的连 Photoshop）：

```powershell
node "C:\ps自制插件\tools\selftest.js"
# 期望输出：通过 40 项，失败 0 项
```

覆盖范围：文档信息解析、选区路径解析（含“无选区 / 选区过小”）、
两个功能发出的 batchPlay 描述符、智能对象拦截、背景层放行、
按钮事件端到端链路、无选区时的提示文案。
